Every app Pake builds has these shortcuts, on top of the ones the website itself defines.

| Mac       | Windows and Linux | Action                              |
| --------- | ----------------- | ----------------------------------- |
| `⌘ [`     | `Ctrl [`          | Go back                             |
| `⌘ ]`     | `Ctrl ]`          | Go forward                          |
| `⌘ ↑`     | `Ctrl ↑`          | Scroll to the top of the page       |
| `⌘ ↓`     | `Ctrl ↓`          | Scroll to the bottom of the page    |
| `⌘ R`     | `Ctrl R`          | Reload the page                     |
| `⌘ W`     | `Ctrl W`          | Hide the window without quitting    |
| `⌘ -`     | `Ctrl -`          | Zoom out                            |
| `⌘ =`     | `Ctrl =`          | Zoom in                             |
| `⌘ 0`     | `Ctrl 0`          | Reset zoom                          |
| `⌘ L`     | `Ctrl L`          | Copy the current page URL           |
| `⌘ ⇧ ⌥ V` | `Ctrl Shift V`    | Paste and match style               |
| `⌘ ⇧ H`   | `Ctrl Shift H`    | Go to the home page                 |
| `⌘ ⇧ ⌫`   | `Ctrl Shift Del`  | Clear the cache and restart         |
| `⌃ ⌘ F`   | `F11`             | Toggle fullscreen                   |
| `⌘ ⌥ I`   | `Ctrl Shift I`    | Toggle developer tools (debug only) |

## Shortcuts that need an option

| Mac     | Windows and Linux | Action                | Build with                                    |
| ------- | ----------------- | --------------------- | --------------------------------------------- |
| `⌘ F`   | `Ctrl F`          | Find in the page      | [`--enable-find`](cli-usage.md#enable-find)   |
| `⌘ G`   | `Ctrl G`          | Find the next match   | [`--enable-find`](cli-usage.md#enable-find)   |
| `⌘ ⇧ G` | `Ctrl Shift G`    | Find the previous one | [`--enable-find`](cli-usage.md#enable-find)   |
| `⌘ N`   |                   | Open a new window     | [`--multi-window`](cli-usage.md#multi-window) |

## Mouse and trackpad

Double-click the title bar to toggle fullscreen. On Mac, swipe to go back or forward and drag the title bar to move the window; the menu bar also has navigation, zoom and window controls. On Windows and Linux, [`--hide-window-decorations`](cli-usage.md#hide-window-decorations) gives a frameless window with a drag region at the top.
