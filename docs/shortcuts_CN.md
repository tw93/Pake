# 快捷键

<div align="center">

[English](shortcuts.md) · **中文**

</div>

Pake 打包出来的每个应用都带下面这些快捷键，网站自己定义的快捷键照常可用。

| Mac       | Windows 和 Linux | 功能                       |
| --------- | ---------------- | -------------------------- |
| `⌘ [`     | `Ctrl [`         | 返回上一页                 |
| `⌘ ]`     | `Ctrl ]`         | 前进到下一页               |
| `⌘ ↑`     | `Ctrl ↑`         | 滚动到页面顶部             |
| `⌘ ↓`     | `Ctrl ↓`         | 滚动到页面底部             |
| `⌘ R`     | `Ctrl R`         | 刷新页面                   |
| `⌘ W`     | `Ctrl W`         | 隐藏窗口，不退出应用       |
| `⌘ -`     | `Ctrl -`         | 缩小页面                   |
| `⌘ =`     | `Ctrl =`         | 放大页面                   |
| `⌘ 0`     | `Ctrl 0`         | 重置缩放                   |
| `⌘ L`     | `Ctrl L`         | 复制当前页面网址           |
| `⌘ ⇧ ⌥ V` | `Ctrl Shift V`   | 粘贴并匹配样式             |
| `⌘ ⇧ H`   | `Ctrl Shift H`   | 回到首页                   |
| `⌘ ⇧ ⌫`   | `Ctrl Shift Del` | 清除缓存并重启             |
| `⌃ ⌘ F`   | `F11`            | 切换全屏                   |
| `⌘ ⌥ I`   | `Ctrl Shift I`   | 开关开发者工具（仅调试版） |

## 需要打包参数的快捷键

| Mac     | Windows 和 Linux | 功能         | 打包时加上                                       |
| ------- | ---------------- | ------------ | ------------------------------------------------ |
| `⌘ F`   | `Ctrl F`         | 在页面中查找 | [`--enable-find`](cli-usage_CN.md#enable-find)   |
| `⌘ G`   | `Ctrl G`         | 查找下一个   | [`--enable-find`](cli-usage_CN.md#enable-find)   |
| `⌘ ⇧ G` | `Ctrl Shift G`   | 查找上一个   | [`--enable-find`](cli-usage_CN.md#enable-find)   |
| `⌘ N`   |                  | 打开新窗口   | [`--multi-window`](cli-usage_CN.md#multi-window) |

## 鼠标和触控板

双击标题栏可以切换全屏。Mac 上可以用手势滑动返回和前进，拖动标题栏移动窗口，菜单栏里也有导航、缩放和窗口控制。Windows 和 Linux 上加 [`--hide-window-decorations`](cli-usage_CN.md#hide-window-decorations) 会得到无边框窗口，顶部留一块拖拽区域。
